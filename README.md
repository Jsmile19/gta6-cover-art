Make original neon coast posters from your own photos in a browser. The studio runs offline with no build step. Photos stay on your device.

Run `node serve.ts --port 8080` and open http://localhost:8080.

1. Choose **Hero + three**, **Four grid**, or **Full bleed**.
2. Click any panel to load a photo. Drag to reposition it and use the wheel or Zoom slider to change its crop. To reuse the selected photo, choose **Fill all panels with this photo**.
3. Pick a grade and edit the title and subtitle.
4. Choose square (1080 × 1080), portrait (1080 × 1350), or wide (1920 × 1080), then click **Export PNG**. **Export all three** downloads one PNG in each size. If your browser asks to allow multiple downloads, allow them for this page.

Open `/?shot=editor` to try the editor with a bundled sample.
